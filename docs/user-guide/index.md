# TermConnect User Guide

For WordPress site owners and content editors who configure and use the plugin.

TermConnect connects WordPress taxonomy terms to the global web of knowledge. Attach external links — knowledge-base identifiers (Wikidata, GeoNames, LCSH), peer WordPress site URLs, RSS/Atom feeds, or any custom link type — to anchor terms to shared reference points. Delegate term definitions to more authoritative sources. Mirror shared vocabularies from peer sites so your editors work with the same terms as the wider community. Pull related content from a network of peers using those shared terms as the matching key.

For the PHP API, hooks, REST fields, and settings keys, see the [Developer Reference](../developer-reference/).

- **[Shared Vocabularies](shared-vocabularies.html)** — mirroring a peer's term structure into your local taxonomy.
- **[Settings, Cache & Export](settings-export.html)** — global settings, cache tools, and export/import.
- **[Displaying Peer Posts](displaying-peer-posts.html)** — `[tc_peer_posts]`, the interactive `[tc_peer_browse]` topic browser, their blocks, and blending peers into `[ht_related_posts]`.
